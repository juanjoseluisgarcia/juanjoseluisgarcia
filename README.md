## AI-assisted engineering

I use **Codex, GitHub Copilot and Claude** as part of a disciplined engineering workflow. They help accelerate codebase discovery, documentation and test scaffolding, explore implementation and refactoring options, and draft small, well-scoped changes.

The productivity gain is time redirected from routine exploration and first drafts towards product decisions, integration risks, edge cases, tests and review. Generated output is treated as a starting point: I validate it through code review, automated testing, targeted checks and architectural judgement before it is merged.
